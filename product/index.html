What it is

Shared world template

Policies, maps, tools, corpora, simulation state—registered once as the organizational rhyme.

Per-agent deltas

Pose, goals, inventory, local memory. Only what differs from the shared world.

Selective reconstruct

Nested vectors let an agent pull only the scales it needs—runtime DRAM, not just file size.

Why DRAM is the engine

FractiSI Multi-Agent is the product name; Tiny Footprint is Layer A. DRAM concurrency is how it pays: more agents in the same memory budget when the shared world would otherwise be copied N times. Network fan-out and durable template stores are phase-2 adapters—not separate diluted SKUs.

What measurement shows so far

Multi-agent labs (synthetic shared worlds): when each agent embeds a full world copy, Tiny’s shared pack still shows large cuts after gzip—about ~42% residual in smaller-world shine labs, and much larger when the world dominates per-agent state. Resident-byte proxies and 8 GiB density arithmetic show order-of-magnitude more agents in the world-dominated regime. Selective coarse-only nested tasks cut runtime working-set bytes by about ~99.5% vs shipping full pyramids.
