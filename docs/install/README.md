# Install

User guide: **[INSTALL.md](./INSTALL.md)**

**Required for full try:** Git + `VERCEL_TOKEN` or `FRACTISI_CLOUD_TOKEN` + Node 18+.

```bash
git clone https://github.com/FractiAI/FractiSI-Multi-Agent.git
cd FractiSI-Multi-Agent
export VERCEL_TOKEN=…
node scripts/tiny.mjs try
```

What to expect: agent worktrees → compose → git commit → live preview URL.  
Tiny Footprint stays Layer A inside FractiSI Multi-Agent.
