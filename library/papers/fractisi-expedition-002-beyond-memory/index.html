Beyond Memory Savings

Testing whether Tiny Footprint Multi-Agent improves speed, accuracy, convergence, discovery, and collective problem-solving — not only DRAM footprint.

Honesty boundary

Digital architectural lab. Suite receipts cover structured-state resource proxies and a constrained multi-hop discovery board. Not live GPU HBM attestation. Not an LLM multi-agent bake-off. Selective reconstruction can be slower than direct shared lookup. Brochure program-map figures without suite receipts stay labeled targets. Application companion — not ENGINE_SHELF.

Central question

Can reorganizing shared information enable a population of agents to produce more useful collective intelligence per unit of infrastructure?

Suite findings (seed 20261105)

≥95%dup cut vs full-copy (large N)
~37–62×faster vs full-copy (this harness)

Relationship-guided reconstruction used ~85% fewer information-processing operations and ~50% fewer modeled coordination rounds on the six-hop board. Conventional shared state already captures much of the basic resource efficiency — so the unique signal here is discovery under constraint, not “shared bytes alone.”

What is not claimed

LLM agents have not yet been shown to reason more accurately, converge faster in dialogue, or deliver more useful work per production dollar with FractiSI. That is the next decisive experiment: same models, prompts, tools, information, and budgets — only the information architecture changes.
